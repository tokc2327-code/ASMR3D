# asmr3d空间渲染器 v0.1 测试版

## 绿色便携版

1. 解压 `asmr3d-v0.1-win-x64.zip`。
2. 打开解压后的 `asmr3d-v0.1-win-x64` 文件夹。
3. 双击：

```text
asmr3d空间渲染器.exe
```

不需要安装 Node.js、浏览器插件或服务端程序。

## 功能

- 内置 4 条示例素材。
- 支持选择本地音频文件。
- 双耳兼容（推荐）默认模式。
- 浏览器 HRTF、参数化 HRTF 和 Bypass。
- 方位、仰角、距离和音量调整。
- 完整文件离线渲染。
- 5～120 秒实时片段导出。
- 16-bit / 24-bit WAV。
- 保存时使用 Windows 系统文件对话框。

## 系统要求

```text
Windows 10 或 Windows 11，64 位
```

## 说明

- 本版本未购买商业代码签名证书，Windows SmartScreen 可能提示未知发布者。
- 导出长文件会产生较高内存占用。
- 建议先将 WAV 导出为 16-bit 进行测试。
