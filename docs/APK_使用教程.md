# asmr3d空间渲染器 v0.1 测试版

## Android APK 使用教程

### 1. 安装前确认

APK 文件：

```text
asmr3d空间渲染器-v0.1测试版.apk
```

系统要求：

```text
Android 7.0 或更高版本
```

建议预留：

```text
至少 500 MB 可用空间
```

完整文件离线导出会占用较多内存和临时空间，导出长音频时建议预留更多空间。

### 2. 把 APK 发送到手机

可以通过以下任意方式发送：

- 微信文件传输助手；
- QQ 文件传输；
- USB 数据线；
- 手机浏览器下载；
- 网盘或局域网传输。

建议把 APK 保存到手机的“下载”目录，方便查找。

### 3. 安装 APK

1. 打开手机“文件管理”或“下载”目录。
2. 点击 `asmr3d空间渲染器-v0.1测试版.apk`。
3. Android 可能提示“未知来源应用”或“此来源的应用”。
4. 根据提示进入安装权限页面。
5. 允许当前文件管理器或浏览器安装未知应用。
6. 返回安装页面，点击“安装”。
7. 如果 Google Play Protect 提示未知应用，确认文件来源可靠后选择继续安装。
8. 安装完成后，桌面会出现“asmr3d空间渲染器”图标。

### 4. 打开应用

从手机桌面点击：

```text
asmr3d空间渲染器
```

第一次打开不需要联网，也不需要额外登录。

### 5. 界面说明

#### 声音对象

用于选择要处理的音频：

- “步骤 1 素材”：应用内置的测试音频；
- “本地音频文件”：从手机中选择自己的音频；
- “播放”：开始播放；
- “暂停”：暂停播放；
- “停止”：停止并回到开头；
- “循环”：音频结束后自动重新播放。

#### 渲染方式

应用提供四种模式：

| 模式 | 用途 |
|---|---|
| 双耳兼容（推荐！） | KU100、假人头、普通双耳或立体声成品的整体空间调整 |
| 浏览器 HRTF | 对单声道对象进行快速 HRTF 渲染 |
| 参数化 HRTF | 使用 ILD、ITD、头部阴影和仰角滤波进行渲染 |
| Bypass | 保留原始左右声道，用于 A/B 对照 |

普通 KU100 或已完成混音的双耳 ASMR 文件建议使用：

```text
双耳兼容（推荐！）
```

该模式不会把原始双耳录音压成单声道，而是保留左右声道，对整体声场进行调整。

#### 空间参数

- 方位角：`−90°～+90°`；
- 仰角：`−30°～+30°`；
- 距离：`0.2～10 米`；
- 输出音量：`0%～100%`；
- “复位”：恢复默认参数。

参数调整是实时的，播放过程中也可以改变。

#### 音频播放进度

- 显示当前播放时间和总时长；
- 拖动进度条可以跳转；
- “后退 10 秒”和“前进 10 秒”可快速定位。

### 6. 播放内置素材

1. 在“步骤 1 素材”下拉框中选择一个声音。
2. 选择“双耳兼容（推荐！）”。
3. 点击“播放”。
4. 调整方位角、仰角、距离和音量。
5. 使用进度条切换试听位置。

### 7. 播放手机中的音频

1. 点击“选择文件”。
2. 在 Android 文件选择器中选择本地音频。
3. 推荐选择以下格式：

```text
WAV、FLAC、OGG、MP3、M4A
```

4. 文件载入后点击“播放”。
5. 如果音频是 KU100 或双耳录音，请使用“双耳兼容（推荐！）”。

### 8. 调整渲染效果

#### 左右方向

调整“方位角”：

- `−90°`：整体声场尽量移向左侧；
- `0°`：保持原始位置；
- `+90°`：整体声场尽量移向右侧。

#### 上下高度

调整“仰角”：

- `−30°`：向下；
- `0°`：水平；
- `+30°`：向上。

高度主要是主观听感，不等于从原始录音中恢复真实仰角。

#### 远近

调整“距离”：

- `0.2 米`：非常近；
- `1 米`：近场；
- `10 米`：远距离。

距离控制会联动音量、高频吸收、近场低音和混响。

### 9. 导出完整 WAV

1. 先选择音频并设置好渲染模式。
2. 调整方位角、仰角、距离和音量。
3. 在“导出成品音频”中设置：

```text
导出范围：完整文件（离线渲染）
WAV 位深：16-bit PCM 或 24-bit PCM
```

4. 点击“开始导出”。
5. 应用会读取并解码完整音频。
6. 然后应用当前空间参数进行离线渲染。
7. 渲染完成后编码为 WAV。
8. 文件会保存到：

```text
Documents/asmr3d/
```

9. 保存完成后会打开 Android 系统分享面板。

推荐：

- 手机测试优先使用 `16-bit PCM`；
- 长音频优先使用 `16-bit PCM`；
- 导出期间保持应用在前台；
- 不要在导出长文件时锁屏或清理后台应用。

### 10. 导出指定片段

1. 在“导出范围”中选择：

```text
指定片段（实时捕获）
```

2. 选择起点：

- 当前播放进度；
- 文件开头。

3. 选择导出时长：

```text
5、15、30、60 或 120 秒
```

4. 选择 WAV 位深。
5. 点击“开始导出”。
6. 导出会按照实际播放速度进行。
7. 导出期间不要锁屏或长时间离开应用。

### 11. 导出文件在哪里

默认保存目录：

```text
内部存储/Documents/asmr3d/
```

不同手机品牌可能显示为：

```text
文档/asmr3d/
文件/文档/asmr3d/
```

如果没有立即看到文件，可以：

1. 等待保存完成；
2. 打开系统文件管理器；
3. 搜索 `asmr3d`；
4. 搜索 `.wav`；
5. 或者在系统通知中查看保存结果。

### 12. 常见问题

#### 提示“应用未安装”

可能原因：

- Android 版本低于 7.0；
- APK 文件没有下载完整；
- 手机中已安装相同包名但签名不同的旧版本；
- 存储空间不足。

处理方式：

- 重新复制 APK；
- 删除旧版本后重新安装；
- 检查剩余存储空间。

#### 无法打开未知来源安装

在 Android 设置中搜索：

```text
安装未知应用
```

然后允许当前文件管理器或浏览器安装应用。

#### 没有声音

检查：

- 手机媒体音量；
- 是否插入耳机；
- 是否点击了“播放”；
- 当前输出设备是否正确；
- 是否处于 Bypass 或某个处理模式。

#### 选择文件后不能播放

建议：

- 把文件复制到“下载”或“文档”目录后重试；
- 更换为 WAV、FLAC 或 OGG；
- 避免读取受保护或加密的音频文件；
- 重新启动应用。

#### 完整导出很慢

完整导出需要解码全部音频，再完成离线渲染和 WAV 编码。

长音频可以：

- 使用 16-bit WAV；
- 关闭其他大型应用；
- 保持屏幕和应用在前台；
- 改用“指定片段”先导出一小段测试。

#### 导出时提示内存不足

处理方式：

- 使用 16-bit；
- 缩短音频；
- 改用指定片段；
- 清理手机后台应用；
- 确保手机剩余存储空间充足。

#### 导出后找不到文件

打开系统文件管理器，进入：

```text
Documents/asmr3d/
```

也可以在导出结束后使用系统分享面板保存到其他位置。

### 13. 卸载应用

1. 长按桌面上的“asmr3d空间渲染器”图标。
2. 选择“卸载”。
3. 根据系统提示确认。

卸载应用不会自动删除已经导出的 WAV 文件。导出文件仍然保存在：

```text
Documents/asmr3d/
```
