# asmr3d Spatial Renderer v0.1 Test Build

## Install

1. Copy `asmr3d-v0.1-test.apk` to an Android phone.
2. Open the APK in the phone file manager.
3. Allow installation from this source when Android asks.
4. Launch `asmr3d空间渲染器` from the home screen.

## Requirements

```text
Android 7.0 or newer
```

## Use

1. Select a built-in sample or tap `选择文件` to load an audio file from the phone.
2. Keep `双耳兼容（推荐！）` for KU100, dummy-head, or normal stereo audio.
3. Adjust azimuth, elevation, distance, and output volume.
4. Choose `完整文件（离线渲染）` or `指定片段（实时捕获）`.
5. Select 16-bit or 24-bit WAV.
6. Tap `开始导出`.

The WAV file is saved to:

```text
Documents/asmr3d/
```

The system share sheet opens after saving so the file can be shared or copied.
