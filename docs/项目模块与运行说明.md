# asmr3d空间渲染器 · 模块、运行方式与环境依赖（v0.2）

## 一、这是什么

一个本地运行的空间音频渲染工具：把单声道/双耳素材或**直播音频**做 HRTF /
双耳兼容处理，实时调参试听，并导出 WAV。

三种交付形态：

| 形态 | 状态 | 目录 |
|---|---|---|
| Windows 便携版 EXE | **当前主目标** | `dist/asmr3d-v0.3-win-x64/` |
| 网页版 / 手机 PWA | 可用 | `renderer/`、`dist/asmr3d-v0.3-mobile/` |
| Android APK | 暂停（第三方工具链风险） | `android/` |

## 二、模块与职责

### 1. 渲染进程 `renderer/` —— 界面与全部音频算法

| 文件 | 功能 |
|---|---|
| `app.js` | 前端主逻辑：Web Audio 图、四种渲染方式、空间参数与 TXT 模板、播放进度、WAV 导出、视频转音频、直播输入接入 |
| `index.html` | 界面结构（左：音源/渲染/参数/导出；中：进度/转换/遥测；右：直播截获；底：已实现方法） |
| `styles.css` | 主题：粉色强调色 + 背景图 + 毛玻璃面板 |
| `live-capture-worklet.js` | AudioWorklet，环形缓冲，把 IPC 送来的 PCM 无抖动地送进音频图 |
| `server.mjs` | 开发/局域网静态服务器：素材 API、ogg Range 请求、移动包目录 |
| `background.jpg`、`icon-*` | 背景图与全尺寸图标（EXE 图标由这些 PNG 合成） |

音频链路（所有渲染方式共用）：

```text
素材 / 直播输入 → 单声道总线 → HRTF 或参数化 → 主音量 → 限幅器 → 监听
                              ↘ 双耳兼容 / Bypass        ↘ 录制分流（耳机之前）
```

### 2. 桌面主进程 `desktop/` —— 只有 EXE 版会运行

| 文件 | 功能 |
|---|---|
| `main.cjs` | 创建窗口、IPC 中枢、决定统一输出文件夹、下载落盘、崩溃后会话音量恢复 |
| `preload.cjs` | `contextBridge` 白名单，渲染进程只能调用暴露出来的方法 |
| `live-capture.cjs` | 枚举系统音频会话、挑选 PowerShell、启动捕获脚本、解析 stdout 的头部 JSON + PCM、分块转发 |
| `segment-recorder.cjs` | 分段 WAV 写入、格式校验、合并、SHA-256、超 4 GB 自动 RF64 |

### 3. 原生捕获 `tools/probe_process_audio.ps1`

内嵌 C# 通过 WASAPI 做 **进程回环**（`ActivateAudioInterfaceAsync` +
`VAD\Process_Loopback`），对外提供：

- `-ListJson`：列出活跃音频会话（PID、进程名、峰值）
- `-StreamToStdout`：输出一行 JSON 头 + 交错 float32 实时 PCM
- `-SetVolume` / `-GetVolume` / `-SetMute`：会话音量读写（用于压低原声）
- 父进程看门狗：宿主异常退出时兜底恢复音量

### 4. 构建与工具 `tools/`

| 脚本 | 用途 |
|---|---|

| `bundle_powershell.mjs` | 复制一份精简版 PowerShell 7 进包，最终用户无需另装 |
| `build_mobile.mjs` | 生成网页/手机包（内嵌 4 条示例素材 + Service Worker） |
| `build_android.ps1`、`create_android_keystore.ps1` | APK 构建（当前暂停） |
| `make_icons.ps1` | 从一张图生成全尺寸图标与 `icon.ico` |
| `fetch_materials.mjs`、`material_scan.mjs` | 素材抓取与清单扫描 |
| `build_github_package.mjs`、`github_upload.mjs` | 生成 GitHub 源码包/发布包并上传 |
| `build_context_bundle.mjs` | 生成项目上下文摘要包 |
| `live_capture_smoketest.mjs` | 命令行验证直播捕获 |
| `recorder_selftest.mjs` | 分段录制/合并自检 |
| `inspect_wav.mjs` | 检查任意 WAV 的格式、时长、峰值、RMS |
| `cdp_live_test.mjs`、`app_screenshot.mjs` | 通过调试端口驱动/截图运行中的应用 |
| `probe_audio_output.ps1`、`measure_process_tree.ps1`、`run_live_capture_probe.ps1` | 早期可行性与性能测量 |

## 三、运行方式

### A. 最终用户：Windows EXE

1. 解压 `dist/asmr3d-v0.3-win-x64.zip`
2. 双击 `asmr3d空间渲染器.exe`
3. 所有成品（导出 WAV、直播录制、转好的音频、参数模板 TXT）都写入
   **exe 同级目录的 `输出` 文件夹**（不存在会自动创建）

### B. 网页版 / 局域网手机版（开发或临时试用）

```powershell
node .\renderer\server.mjs
```

- 电脑：<http://127.0.0.1:4173/>
- 手机（同一 Wi-Fi）：`http://<电脑局域网IP>:4173/mobile/`
- 改端口：`$env:PORT=8080; node .\renderer\server.mjs`

### C. 桌面开发模式（改代码时用）

```powershell
node .\renderer\server.mjs                      # 终端 1
node_modules\electron\dist\electron.exe .\desktop\main.cjs   # 终端 2
```

此时输出目录为项目的 `dist\输出`。

### D. 重新打包

```powershell
npm run exe:release      # 等价于 node tools/build_exe.mjs
npm run build:mobile
```

## 四、依赖环境

### 最终用户（跑 EXE）

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 x64 |
| 运行库 | 无（Electron 运行时 + 精简版 PowerShell 7 都已打进包里） |
| Node / Python / ffmpeg | **都不需要** |
| 直播截获 | 直接用包内 `resources\pwsh\pwsh.exe`，**不需要**单独安装 PowerShell 7 |

内置的 PowerShell 7 已去掉 WPF/WinForms（捕获脚本是纯命令行负载，用不到）：

```text
官方 win-x64 解压版 244.7 MB  →  精简后 192 MB（压缩后约 82 MB）
保留 ref\（Add-Type 编译必需）与 Roslyn（Microsoft.CodeAnalysis）
随包附带 LICENSE.txt 与 ThirdPartyNotices.txt
```

程序解析 PowerShell 的优先级（`desktop/live-capture.cjs`）：

```text
ASMR3D_POWERSHELL 环境变量（调试用）
  → 包内 resources\pwsh\pwsh.exe（正常走这条）
  → PATH 上的 pwsh
  → Program Files / LOCALAPPDATA 常见安装位置
  → 都没有时才退回 Windows PowerShell 5.1（会提示不支持进程回环）
```

## 五、功能 ↔ 环境依赖对照

| 功能 | 依赖 | 说明 |
|---|---|---|
| 内置素材库 / 导入本地文件播放 | 无 | 纯 Web Audio |
| 四种渲染方式、空间参数实时调节 | 无 | |
| 参数模板 TXT 导入/导出 | 无 | 导出经桌面下载通道落盘 |
| 完整文件离线导出、片段实时导出 | 无 | 长音频吃内存，见提示 |
| 视频/音频转 WAV | Chromium 内置解码器 | 不依赖 ffmpeg；单文件上限 4 GB |
| 直播截获（按应用） | Windows + PowerShell 7 | 进程回环，只抓所选应用 |
| 同步录制成品 | 同上 + 磁盘空间 | 分段写盘，结束合并 |
| 手机版 / PWA | 浏览器 | 安装到主屏需 HTTPS 或 localhost |
| Android APK | JDK + Android SDK | 当前暂停 |

## 六、运行时路径与状态

| 内容 | 位置 |
|---|---|
| 成品输出目录 | `<EXE目录>\输出`（开发模式 `dist\输出`） |
| 捕获脚本 | `<EXE目录>\resources\probe_process_audio.ps1` |
| 内置 PowerShell | `<EXE目录>\resources\pwsh\pwsh.exe` |
| 会话音量恢复状态 | `%APPDATA%\asmr3d空间渲染器\source-volume-state.json` |
| 临时分段与元数据 | 输出目录内 `*.partNNN.wav` / `*.segments.json`（合并成功后删除） |

## 七、已知限制

- 直播截获只支持 Windows；便携包已内置精简版 PowerShell 7，若把 `resources\pwsh` 删掉则需要系统自行安装。
- 只做**按应用**捕获；系统输出回环因会把自身输出抓回去产生自激，已移除。
- 视频转音频不支持 MKV（Chromium 无法解该封装），H.265/AC3 等也可能失败。
- 长音频导出的解码缓冲常驻内存，因此有内存门槛提示。
- 参数模板的越界值会被限幅而不是报错，方便手改。
