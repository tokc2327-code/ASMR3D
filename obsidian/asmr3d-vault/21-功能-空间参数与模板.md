# 21 功能：空间参数与模板

[[00-索引]] · 相关：[[20-功能-渲染方式]] · [[22-功能-导出与分段渲染]]

## 空间参数

| 参数 | 范围 | 方向 / 含义 |
|---|---:|---|
| 方位角 | `-90°～+90°` | `-90°` 左，`0°` 前，`+90°` 右 |
| 仰角 | `-30°～+30°` | 负值向下，正值向上 |
| 距离 | `0.2～10 m` | 对数滑块，`0.2 m` 为参考 |
| 输出音量 | `0～100%` | master 输出增益 |
| 渲染方式 | 四选一 | `binaural` / `hrtf` / `parametric` / `bypass` |

### 距离滑块映射

距离用对数映射，避免线性滑块把大量行程浪费在远距离：

```text
slider = log(distance / 0.2) / log(50)
distance = 0.2 × 50^slider
```

### 参数与算法

| 参数 | 双耳兼容 | 浏览器 HRTF | 参数化 HRTF |
|---|---|---|---|
| 方位角 | StereoPanner | Panner 位置 | ILD / ITD / 头部阴影 |
| 仰角 | 高度 EQ | Panner Y | 仰角搁架 / 峰值 EQ |
| 距离 | 增益 / 吸收 / 近场 / 混响 | Panner inverse | 增益 / 吸收 / 近场 / 混响 |
| 输出音量 | master | master | master |

具体公式见 [[20-功能-渲染方式]]。

## 参数模板 TXT

「空间参数」面板底部支持模板导入和导出。

### 导出格式

```text
# asmr3d空间渲染器 · 空间参数模板 v1
# 每行一个参数，用 = 或 : 分隔；# // ; 开头的行是注释
# 数值可带单位，例如 0.4 m、80%、-12.5°

模板名称 = Food - Eating a fruit
方位角 = 30.0
仰角 = 12.0
距离 = 1.53
输出音量 = 66
渲染方式 = parametric
# 渲染方式可选：binaural / hrtf / parametric / bypass
```

### 解析规则

| 规则 | 行为 |
|---|---|
| 分隔符 | `=`、`:`、`：` |
| 注释 | 以 `#`、`//`、`;` 开头的整行忽略 |
| 空行 | 忽略 |
| 键名 | 中英文均可，不区分大小写，忽略空格 |
| 数值单位 | 自动剥离 `m`、`%`、`°` |
| 越界 | 自动限幅，不报错 |
| 未知行 | 跳过，并提示忽略行数 |
| 模板名称 | 只作备注，不参与计算 |

### 支持的键名

| 参数 | 写法 |
|---|---|
| 方位角 | `方位角`、`方位`、`水平角`、`azimuth`、`azimuthdeg` |
| 仰角 | `仰角`、`高度角`、`elevation`、`elevationdeg` |
| 距离 | `距离`、`distance`、`distancem` |
| 输出音量 | `输出音量`、`音量`、`volume`、`gain` |
| 渲染方式 | `渲染方式`、`模式`、`mode`、`rendermode` |
| 模板名称 | `模板名称`、`name` |

### 渲染方式别名

| 内部值 | 可接受文字 |
|---|---|
| `binaural` | `双耳兼容`、`双耳`、`compatibility` |
| `hrtf` | `浏览器HRTF`、`browserHRTF` |
| `parametric` | `参数化HRTF`、`参数HRTF` |
| `bypass` | `直通`、`跳过` |

### 限幅行为

```text
方位角 → -90～+90
仰角   → -30～+30
距离   → 0.2～10
音量   → 0～100
```

越界值被限制到边界，并在状态栏说明。这样可以把模板当作基线，只改其中一两行。

### 导入后的立即效果

导入后：

1. 更新模式；
2. 更新滑块；
3. 更新读数；
4. 更新声像位置；
5. 更新 Web Audio 链；
6. 如果正在播放，实时反映到听感。

## 导出位置与命名

模板写入统一输出目录，例如：

```text
Food - Eating a fruit_空间参数_2026-10-04T09-35-20.txt
```

目录规则见 [[22-功能-导出与分段渲染]]。

## 模型实现提示

- 解析器在 `renderer/app.js`：`parseSpatialTemplate`、`applySpatialTemplate`、`buildSpatialTemplateText`。
- 模板导入必须走与滑块的同一套状态更新，不能只改 DOM。
- 越界应限幅，不要拒绝整份模板。
- 新增参数时要同步导出格式、解析别名、Wiki 和测试。
