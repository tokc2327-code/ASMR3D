## 便携版体积构成

压缩包约 **233.8 MB**，解压约 **562 MB**。

| 组成 | 压缩后约 | 说明 |
|---|---:|---|
| `asmr3d空间渲染器.exe` | 104.7 MB | Chromium / Electron |
| `resources\pwsh` | 83.1 MB | 自包含 .NET 9 + Roslyn |
| `locales` 55 个 `.pak` | 12.9 MB | 多语言 |
| `resources.pak` | 11.8 MB | Chromium 资源 |
| `dxcompiler.dll` + `dxil.dll` | 10.0 MB | GPU / 着色器 |
| `icudtl.dat` | 4.6 MB | Unicode 数据 |
| `resources\app.asar` | 2.6 MB | 自有代码、素材、图标 |
| `LICENSES.chromium.html` | 2.5 MB | 第三方许可 |
| `vk_swiftshader.dll` | 2.1 MB | 软件 Vulkan |

```text
renderer/app.js             约 102 KB

```

结论：体积主要来自 Chromium 和内置 PowerShell 7，不是业务代码。


```text

```

资源：


## 视频转音频

```text
输入：355 MB / 63.7 分钟 / H.264 + AAC MP4
输出：1024 MB / 24-bit WAV
总耗时：14.5 秒
  ├─ 解码约 7 秒
  └─ 编码约 6 秒

26 秒小文件：0.5 秒
```

这不是实时播放录制，而是完整解码后编码。

内存估算：

```text
decoded = duration × 48000 × 2 × 4
peak = decoded + 源文件大小
```

## 解码边界

Chromium `decodeAudioData` 单次最多约 **2 GiB PCM**。

| 切片 | 时长 | 解码 PCM | 结果 |
|---:|---:|---:|---|
| 200 MB | 87:23 | 1.875 GiB | 通过 |
| 210 MB | 91:45 | 1.969 GiB | 通过 |
| 215 MB | 约 94 分 | 超过 2 GiB | 失败 |

48 kHz 立体声约 93 分钟，44.1 kHz 立体声约 101 分钟。

## MP3 分段离线渲染

```text
源文件：299 MB / 2 小时 11 分 / VBR MP3
分段：5 段 × 约 30 分钟
输出：1.44 GB / 16-bit WAV
耗时：114 秒
总长度：7851.0 秒
与源时长差：0
接缝：前后 1 秒电平连续
理论单接缝损失：小于一个 MP3 帧，约 26 ms
```

可切格式只有 MP3 系：

```text
.mp3 .mp2 .mpga .mpa
```

FLAC、OGG、MP4 / M4A 中段切片实测无法解码，原因是缺少文件头级配置信息。

## WAV 体积

48 kHz 立体声：

| 位深 | 每秒 | 每小时 |
|---|---:|---:|
| 16-bit PCM | 192 KB/s | 约 691 MB |
| 24-bit PCM | 288 KB/s | 约 1.04 GB |

对比：

```text
306 kbps MP3
24-bit / 48 kHz WAV ≈ 2304 kbps
体积比约 7.5 倍
```

用户曾报告输出 WAV 比源 MP3 大很多，这是 PCM 未压缩的正常结果。
