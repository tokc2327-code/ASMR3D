# v0.3.1 新聊天交接

## 一句话

asmr3d空间渲染器 v0.3.1 是本地离线的 ASMR / 双耳 / 空间音频工具，
支持本地素材、直播截获、实时参数调整、模板预设、离线 WAV 导出和视频转音频。

- 对外版本：v0.3.1 公测版

- 静音自动停止默认关闭，压低原声时静音阈值按捕获缩放修正

## 主要功能

- 四种渲染方式：双耳兼容、浏览器 HRTF、参数化 HRTF、Bypass
- 参数范围：方位角 ±90°、仰角 ±30°、距离 0.2–10 m、音量 0–100%
- 近距离保护：0.2–0.35 m 使用 spatial guard，近场低频上限 3 dB
- TXT 空间参数模板导入/导出
- 直播截获：Windows 按应用进程回环
- 原声压低：−60 dB，渲染链补偿上限 +66 dB
- 同步录制：分段写盘、结束合并、SHA-256
- 完整离线导出、指定片段、30 秒/2 分钟/5 分钟/自定义
- 快速导出：短卷积混响
- 导出阶段计时：读取/解码/渲染/编码/写盘
- 视频转音频：Chromium 内置解码器，不依赖 ffmpeg
- 浅色 / 深色 / 跟随系统主题
- 设置默认参数和关于页面
- 检查更新发现新版本后可打开对应 Release 下载页

## 运行与构建

```powershell
node .\renderer\server.mjs
node .\tools\build_exe.mjs
node .\tools\build_mobile.mjs
node .\tools\build_github_package.mjs
node .\tools\github_upload.mjs
```

如果源码已经用 `git push` 上传，可设置
`$env:ASMR3D_SKIP_SOURCE_UPLOAD="1"` 再运行上传脚本，只更新 Release 资源。

## 当前已知限制

- 直播截获仅 Windows
- 只支持按应用捕获，不回退系统输出回环
- 视频转换不支持 MKV、H.265、AC3 等解码器不支持的格式
- 长音频离线导出受内存和 RIFF 4 GB 限制
- Android APK 暂停，移动端使用 PWA
- 普通双耳录音不能反解为多个独立对象
