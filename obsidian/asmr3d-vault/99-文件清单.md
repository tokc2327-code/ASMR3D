# 99 文件清单

[[00-索引]] · 模块说明：[[10-模块-渲染进程]] · [[11-模块-桌面主进程]]

以下只列维护项目时需要认识的文件，不展开 `node_modules/`、`dist/`、Android 构建缓存和工具链缓存。

## 不应进入源码包的内容

| 内容 | 原因 |
|---|---|
| `tools/.github-token*` | GitHub 凭据 |
| `node_modules/` | 可重装 |
| `dist/` | 构建产物 |
| `tools/electron-runtime/` | 打包时下载/复制的运行时 |
| `tools/android-build/` | Android 工具链缓存 |
| Android `build/`、`.gradle/` | 构建缓存 |
| 用户输出音频 | 不应随源码发布 |

发布脚本使用自己的 ignore 列表；新增凭据文件时必须同步确认不会进入源码包。
