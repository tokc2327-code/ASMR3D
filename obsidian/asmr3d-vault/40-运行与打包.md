# 40 运行与打包

[[00-索引]] · 相关：[[13-模块-构建与工具脚本]] · [[41-发版流程]]

## 最终用户：Windows 便携版

### 要求

```text
Windows 10 / 11 x64
无需 Node、Python、ffmpeg、PowerShell 7
```

### 步骤

1. 从 Release 下载 `asmr3d-v0.2-win-x64.zip`；
2. 解压到可写目录，例如 `D:\asmr3d\`；
3. 双击 `asmr3d空间渲染器.exe`；
4. 首次运行如遇 SmartScreen，选择“更多信息”后再运行；
5. 所有成品写入 EXE 同级 `输出` 文件夹。

不要把 EXE 单独复制到别处，必须带上 `resources/`、DLL、`locales/` 等完整目录。

### 输出目录

```text
<EXE目录>\输出
```

开发模式：

```text
dist\输出
```

## 网页版

```powershell
node .\renderer\server.mjs
```

访问：

```text
http://127.0.0.1:4173/
```

换端口：

```powershell
$env:PORT=8080
node .\renderer\server.mjs
```

网页版能做：

- 素材播放；
- 四种渲染方式；
- 空间参数；
- TXT 模板；
- WAV 导出；
- 视频转音频。

网页版不能做：

- 按应用直播截获；
- 系统级音频设备控制。

## 手机 PWA

```powershell
node .\renderer\server.mjs
```

电脑终端会输出局域网地址，例如：

```text
http://192.168.1.10:4173/mobile/
```

手机与电脑同一 Wi-Fi 时打开该地址，再用浏览器菜单“添加到主屏幕”。

PWA 需要 HTTPS 或 localhost 才能安装。部署可以把 `dist/asmr3d-v0.2-mobile/` 放到任意静态托管。

## 桌面开发模式

终端 1：

```powershell
node .\renderer\server.mjs
```

终端 2：

```powershell
node_modules\electron\dist\electron.exe .\desktop\main.cjs
```

如果 Electron 尚未安装：

```powershell
npm install
```

开发模式方便调试主进程、IPC 和直播捕获。输出目录为项目的 `dist\输出`。

## 打包 Windows EXE

```powershell
npm run exe:release
```

等价于：

```powershell
node tools\build_exe.mjs
```

构建会：

```text
生成图标
  → 使用 @electron/packager 打包
  → 内置精简版 PowerShell 7
  → 复制捕获脚本
  → 生成移动包
  → 压缩 zip
```

产物：

```text
dist\asmr3d-v0.2-win-x64\
dist\asmr3d-v0.2-win-x64.zip
```

## 构建移动包

```powershell
npm run build:mobile
```

产物：

```text
dist\asmr3d-v0.2-mobile\
dist\asmr3d-v0.2-mobile.zip
```

## 环境变量

| 变量 | 用途 |
|---|---|
| `PORT` | 网页版端口 |
| `ASMR3D_POWERSHELL` | 调试时指定捕获用 PowerShell |
| `ASMR3D_CAPTURE_LOG` | 记录主进程实际启动的命令行 |
| `GITHUB_TOKEN` | GitHub 上传脚本的首选令牌来源 |

## 运行时状态

| 内容 | 位置 |
|---|---|
| 输出 | `<EXE目录>\输出` 或 `dist\输出` |
| 捕获脚本 | `<EXE目录>\resources\probe_process_audio.ps1` |
| 内置 PowerShell | `<EXE目录>\resources\pwsh\pwsh.exe` |
| 会话音量恢复状态 | `%APPDATA%\asmr3d空间渲染器\source-volume-state.json` |
| 临时分段 | 输出目录中的 `*.partNNN.wav` 和 `*.segments.json` |

## 常见开发检查

1. 改过 `app.js` 后先跑 `node --check`；
2. 改过 IPC 后同时检查主进程、preload 和渲染进程；
3. 改过超长文件逻辑后测试 210 MB 边界和 MP3 接缝；
4. 改过 PowerShell 精简规则后启动一次 `pwsh -NoProfile` 并调用捕获脚本；
5. 改过输出版式后重打 EXE，在干净目录启动一次；
6. 改过版本号后检查界面徽标和 zip 文件名是否一致。
