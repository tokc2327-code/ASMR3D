# 14 模块：素材、文档与知识库

[[00-索引]] · 相关：[[99-文件清单]] · [[40-运行与打包]]

## `materials/`：内置素材库

应用内置 30 条 CC0 素材，按用途分五类：

| 类别 | 用途 |
|---|---|
| 01 双耳参考 | 音乐盒、火车、人头录音、后院、淋浴扫动 |
| 02 近场 ASMR | 耳语、指甲敲击、头发梳理、耳清洁、键盘 |
| 03 环境距离 | 雨声、鸟叫、水龙头、旧剧场 |
| 04 测试信号 | 粉噪声、声学测量、脉冲响应 |
| 05 单声道控制 | 吃苹果、键盘、气泡、刷子 |

清单文件：

```text
materials/manifest.json   应用运行时读取
materials/manifest.csv    表格检查
materials/SOURCES.md      来源、作者、许可
materials/README.md       素材库说明
```

新增素材的约束：

1. 录音必须明确标注 CC0；
2. 记录原始链接、作者、下载日期；
3. 不引入来源不明或只允许个人使用的素材；
4. 更新 `manifest` 后测试网页版和移动包路径；
5. 注意素材体积会直接进入 `app.asar`。

`docs/` 记录实现原因和实测过程，优先级高于本知识库的摘要。

| `直播截获实现说明.md` | 进程回环、消回声、分段录制 |
| `步骤1_音频素材准备.md` | 素材来源与分类 |
| `步骤2_单声道对象空间渲染.md` | 空间渲染需求与参数 |
| `步骤2_渲染器实现方式.md` | 四种渲染方式与算法 |
| `实时捕获验证报告.md` | 平台验证和原始数据 |
| `直播录制附属功能设计.md` | 录制模式设计 |

模型在修改实现前，至少应读取：


## 给模型的资料优先级

```text
代码与构建产物
  > docs/ 权威说明
  > wiki/ 用户说明
  > obsidian/ 整理摘要
```

如果摘要和代码冲突，以代码和可复现实测为准，并更新摘要。
