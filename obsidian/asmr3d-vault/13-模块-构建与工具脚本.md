# 13 模块：构建与工具脚本

[[00-索引]] · 相关：[[40-运行与打包]] · [[41-发版流程]]

## npm 脚本

`package.json` 中与项目直接相关的脚本：

```json
{
  "build:mobile": "node tools/build_mobile.mjs",
  "exe:release": "node tools/build_exe.mjs",
  "apk:release": "powershell -NoProfile -ExecutionPolicy Bypass -File tools/build_android.ps1"
}
```

## Windows EXE 构建

### `tools/build_exe.mjs`

流程：

```text
检查 Electron 运行时
  → 生成 / 复用图标
  → 调用 @electron/packager
  → 复制 renderer / desktop / materials 到 app.asar
  → 运行 bundle_powershell.mjs
  → 复制 probe_process_audio.ps1
  → 生成移动包
  → 打 zip
```

主要产物：

```text
dist/asmr3d-v0.2-win-x64/
dist/asmr3d-v0.2-win-x64.zip
```

### `tools/bundle_powershell.mjs`

把官方 PowerShell 7 win-x64 解压版复制进：

```text
dist/asmr3d-v0.2-win-x64/resources/pwsh/
```

精简原则：

- 删除 WPF、WinForms、UIAutomation 相关共 12 个不必要文件；
- **保留 `ref\`**，因为内嵌 C# 编译需要引用程序集；
- 保留 Roslyn 与 `Microsoft.CodeAnalysis`；
- 附带 PowerShell `LICENSE.txt` 与 `ThirdPartyNotices.txt`；
- 官方 244.7 MB 精简到约 192 MB，压缩后约 83 MB。

不要为了省体积删除 `ref\`，否则 `Add-Type` 会失败。

## 移动包

### `tools/build_mobile.mjs`

生成：

```text
dist/asmr3d-v0.2-mobile/
dist/asmr3d-v0.2-mobile.zip
```

移动包包含：

- `renderer/` 的网页资源；
- 4 条内置示例素材；
- 移动端 `manifest.webmanifest`；
- Service Worker；
- 适配手机布局的入口。

移动版只有音频渲染、参数模板、导出和视频转音频，没有直播截获。

## 图标

### `tools/make_icons.ps1`

从一张源图生成：

```text
icon-16/32/48/64/128/192/256/512.png
apple-touch-icon.png
icon.ico
```

源图按中心裁剪成方形。生成后重新构建 EXE 才会更新程序图标：

```powershell
pwsh -File tools\make_icons.ps1 -Source D:\path\avatar.jpg
node tools\build_exe.mjs
```

Windows 资源管理器可能缓存旧图标，必要时重启资源管理器。

## 版本与发布

### `tools/bump_version.mjs`

一次性替换约 20 个文件、70 多处版本字符串，包括：

- `package.json`；
- 界面版本徽标；
- 窗口标题；
- 构建产物目录名和文件名；
- Release 标签；
- README、Wiki、docs 中的当前版本；
- GitHub 上传脚本默认标签。

```powershell
node tools\bump_version.mjs 0.3.1 --dry-run
node tools\bump_version.mjs 0.3.1
```

先跑 `--dry-run` 检查文件数是否正常。正常应覆盖 20 个文件。

### `tools/build_github_package.mjs`

生成：

```text
dist/github-package/source/
dist/github-package/release-assets/
```

源码包目录列表目前为：

```text
renderer desktop docs wiki tools materials android
```

如果要把 `obsidian/` 也上传到源码仓库，需要把 `"obsidian"` 加入该数组。脚本使用自己的 ignore 列表，不读取 `.gitignore`，因此新增令牌、缓存或状态文件时必须同步加入 ignore。

### `tools/github_upload.mjs`

功能：

- 读取 GitHub 令牌；
- 把源码树推送到 `main`；
- 更新仓库描述和 topics；
- 创建或复用 tag；
- 上传 `release-assets/` 中的文件。

注意：推送是 **force 覆盖**，网页上直接修改过的内容会被本地源码树覆盖。

### `tools/push_wiki.mjs`

把 `wiki/` 页面推送到 GitHub Wiki。适合发布前同步用户文档。

## 自测工具

| 文件 | 用途 |
|---|---|
| `live_capture_smoketest.mjs` | 枚举会话或捕获固定秒数 |
| `recorder_selftest.mjs` | 生成多个分段、合并、检查结果 |
| `inspect_wav.mjs` | 检查任意 WAV 的格式和电平 |
| `cdp_live_test.mjs` | 通过远程调试端口驱动应用 |
| `app_screenshot.mjs` | 截取窗口或整页 |
| `measure_process_tree.ps1` | 统计 Electron 进程树 CPU / 内存 |

## 构建注意事项

- `dist/`、`node_modules/` 和工具链缓存不应提交。
- 构建 Windows 包需要能访问 npm 下载 Electron。
- 内置 PowerShell 版本与脚本兼容性需在打包后实测。
- 修改资源清单后要同步 `build_mobile.mjs`、`build_exe.mjs` 与测试。
- 发布前必须同时验证开发模式和打包模式，二者路径解析不同。
