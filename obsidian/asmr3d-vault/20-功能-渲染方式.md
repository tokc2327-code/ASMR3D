# 20 功能：渲染方式

[[00-索引]] · 相关：[[10-模块-渲染进程]] · [[21-功能-空间参数与模板]]

## 四种模式

| 模式 | UI 名称 | 输入 | 本质 |
|---|---|---|---|
| `binaural` | 双耳兼容（推荐） | 立体声 | 保留 L/R，整体移动和调音色 |
| `hrtf` | 浏览器 HRTF | 单声道对象 | `PannerNode` 内置 HRIR |
| `parametric` | 参数化 HRTF | 单声道对象 | 手动合成 ILD、ITD、阴影、耳廓线索 |
| `bypass` | Bypass | 原声 | 只保留音量和限幅 |

## 双耳兼容

### 适用

- KU100 录音；
- 假人头录音；
- 普通双耳成品；
- 已经是立体声、且含有整体空间信息的素材。

### 做什么

```text
Stereo L/R
  → StereoPannerNode
  → 高度音色 EQ
  → 空气吸收低通
  → 近场低频搁架
  → 距离增益
  → 干声 + 合成混响
```

### 关键性质

这是一次**整体声场移动**，不是把某个声源从左边搬到右边。双耳录音里的方向信息已经被编码在左右声道和时间差中，重新下混再加 HRTF 会破坏原有声场。

方位角映射：

```text
pan = sin(方位角)
panner.pan = pan × 0.92
```

使用 `0.92` 留余量，避免极端角度时整体声场被硬推到单侧。

## 浏览器 HRTF

### 适用

- 单声道素材；
- 快速主观试听对象在某个方位的感受；
- 不要求跨平台完全一致的实验。

### 实现

```text
Mono input
  → PannerNode
      panningModel = "HRTF"
      distanceModel = "inverse"
      refDistance = 0.2 m
      maxDistance = 10 m
      rolloffFactor = 1
      coneInnerAngle = 360
  → 输出
```

方位与仰角被转换成三维坐标：

```text
az = 方位角（弧度）
el = 仰角（弧度）
horizontal = distance × cos(el)

x = horizontal × sin(az)
y = distance × sin(el)
z = -horizontal × cos(az)
```

浏览器内部使用的 HRIR 数据集由 Chromium / 操作系统决定，不同环境可能不完全一致。

## 参数化 HRTF

### 适用

- 单声道对象；
- 想观察每条空间线索如何影响听感；
- 想做可解释、可复现的参数实验。

### 四条线索

| 线索 | 实现 | 上限 |
|---|---|---:|
| ILD 双耳声级差 | 对侧增益衰减 | 8 dB |
| ITD 双耳时差 | 对侧声道增加延时 | 0.65 ms |
| 头部阴影 | 对侧高频低通 | 截止最低约 4 kHz |
| 仰角耳廓滤波 | 6.5 / 10.5 kHz 附近的搁架和峰值滤波 | 由仰角比例驱动 |

方位角先转成：

```text
pan = sin(方位角)
```

然后：

```text
左耳增益 = -max(0, pan) × 8 dB
右耳增益 = -max(0, -pan) × 8 dB
左耳延时 = max(0, pan × 0.65 ms)
右耳延时 = max(0, -pan × 0.65 ms)
左耳阴影截止 = 20000 - 16000 × max(0, pan)
右耳阴影截止 = 20000 - 16000 × max(0, -pan)
```

仰角归一化：

```text
elevation = 仰角 / 30
仰角低频搁架 = elevation × 2.2 dB
仰角高频峰值 = elevation × 3.5 dB
```

该模式还会经过合成本地脉冲响应的卷积混响。它不是头部相关脉冲响应数据库，而是用可解释的声学线索近似 HRTF 的主要感知效果。

## Bypass

不加 HRTF、不做场移动、不做距离处理，只经过：

```text
master volume → limiter → output
```

适合 A/B 对照，用来确认空间处理实际改变了什么。

## 距离模型

四种空间模式共用一组距离感知模型，但在各自链路中的节点位置不同。

```text
距离 ↑
  → 1/r 声压衰减（0.2 m 参考）
  → 空气吸收增强（低通截止下降）
  → 1 m 内近场低频提升减弱
  → 混响湿声比例提升
```

参考公式：

```text
距离增益 = 0.2 / distance
空气吸收截止 = 20000 × exp(-0.1 × (distance - 0.2))
近场提升 = 5 dB × max(0, 1 - distance)
湿声比例 = 0.04 + 0.26 × log(distance / 0.2) / log(50)
```

所以距离拉远时声音会同时变小、变闷、变空，而不是单纯降低音量。

## 限幅器

所有模式输出统一进入：

```text
threshold ≈ -2 dB
ratio = 16:1
```

它的作用是避免多条路径叠加或补偿增益导致数字削波，同时也是 [[22-功能-导出与分段渲染]] 和 [[24-功能-直播截获与录制]] 的录制分流参考点。

## 选择建议

```text
KU100 / 假人头 / 双耳成品
  → 双耳兼容

单声道对象，快速试听
  → 浏览器 HRTF

单声道对象，想看可解释线索
  → 参数化 HRTF

只想确认原声
  → Bypass
```

## 不应承诺的能力

- 不能从普通双耳录音中恢复独立声源；
- 不能把双耳录音中的一个隐藏对象精确旋转到任意方位；
- 通用 HRTF 不保证每个人的绝对定位一致；
- 距离是主观模型，不是声学测距。
