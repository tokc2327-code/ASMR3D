# asmr3d空间渲染器 v0.3 公测版

这是一个无需安装前端依赖的本地 Web Audio 渲染器，用于验证步骤 2 的单声道对象空间化流程。

## 运行

```powershell
node .\renderer\server.mjs
```

浏览器打开：

```text
http://127.0.0.1:4173
```

## 已实现

- 从 `materials/manifest.json` 读取步骤 1 素材。
- 立体声和双耳素材通过 Web Audio 显式下混为测试用单声道对象。
- 浏览器内建 HRTF `PannerNode`。
- 参数化 HRTF 近似：ILD、ITD、耳间头部阴影、仰角峰值滤波。
- 双耳兼容模式：保留 KU100 或立体声成品的原始左右声道。
- 距离反比衰减、空气吸收、近场低音和合成混响。
- Bypass A/B 对照。
- 将当前模式和空间参数离线渲染为完整文件，或实时捕获为指定片段。
- 支持 16-bit 和 24-bit PCM WAV 导出。
- 方位角 `−90°～+90°`、仰角 `−30°～+30°`、距离 `0.2～10 m`。
- 不实现头部追踪。
