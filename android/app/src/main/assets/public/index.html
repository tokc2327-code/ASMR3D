已实现方法

0 / 8
  1. 单声道对象化 立体声或双耳输入显式下混为单声道测试总线。
  2. 浏览器 HRTF Web Audio PannerNode 使用浏览器内建 HRIR。
  3. 参数化 HRTF ILD、ITD、头部阴影和耳廓频响近似。
  4. 双耳兼容 保留原始左右声道，只做整体声场和音色调整。
  5. 距离反比 以 0.2 m 为参考，声压按 1/r 衰减。
  6. 空气吸收 距离越远，高频低通截止越低。
  7. 近场低频 1 m 内逐步提升低频，模拟贴近感。
  8. 距离混响 合成衰减脉冲，距离增加时提高湿声比例。
  9. WAV 导出 实时捕获当前渲染结果并编码为 16/24-bit PCM。
  10. 固定输出链 展示 AudioContext 基础输出延时。
