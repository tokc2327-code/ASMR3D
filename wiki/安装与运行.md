# 安装与运行

asmr3d空间渲染器有三种运行形态，按需要选一种即可。

## 方式一：Windows 便携版（推荐）

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11，64 位 |
| 依赖 | **什么都不用装**——Node、Python、ffmpeg、PowerShell 7 都已打进包里 |
| 体积 | 压缩包约 234 MB，解压后约 562 MB |

### 步骤

1. 打开 [Releases](https://github.com/tokc2327-code/ASMR3D/releases/tag/v0.3-beta)，
   下载 `asmr3d-v0.3-win-x64.zip`；
2. 解压到**可写目录**（例如 `D:\asmr3d\`），不要放在 `C:\Program Files` 下——
   成品要写到程序目录里；
3. 双击 `asmr3d空间渲染器.exe`；
4. 首次启动时 Windows 若弹 SmartScreen 提示，选「更多信息」→「仍要运行」即可
   （未做代码签名，属正常现象）。

> 这是绿色便携版，**要整个文件夹一起拷贝**。单独把 exe 复制到别处会缺依赖。

### 卸载

直接删除整个文件夹即可，不写注册表。如果用过直播截获、且程序异常退出过，
可以顺手删掉 `%APPDATA%\asmr3d空间渲染器\` 这个状态目录。

## 方式二：网页版（本机）

适合临时试用，或只想在浏览器里跑：

```powershell
node .\renderer\server.mjs
```

然后打开 <http://127.0.0.1:4173/>。

网页版能用全部**音频**功能（渲染、空间参数、模板、导出、视频转音频），
但**没有**直播截获——那需要桌面版的系统级捕获能力。

## 方式三：手机 / 平板（PWA）

1. 电脑和手机连同一个 Wi-Fi；
2. 电脑上跑 `node .\renderer\server.mjs`，记下终端输出的局域网地址
   （形如 `http://192.168.x.x:4173/mobile/`）；
3. 手机浏览器打开该地址；
4. 浏览器菜单里选「添加到主屏幕 / 安装应用」，即可像 App 一样使用。

想把手机版部署到别处，可以把 `dist/asmr3d-v0.3-mobile` 整个目录上传到任意
静态托管（HTTPS）。注意 PWA 安装到主屏需要 HTTPS 或 localhost。

> Android APK 当前暂停维护（第三方工具链风险），移动端请使用上面的 PWA。

## 怎么确认运行正常

启动后左下角状态栏显示：

```text
素材库已载入，按播放开始测试。
AudioContext：未启动
```

点一次「播放」后，右下角变成类似
`AudioContext：running · 48000 Hz · 12.3 ms`，说明音频链路已经跑起来了。
