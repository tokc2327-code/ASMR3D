# 视频转音频

界面中间「音频播放进度」下方有 **视频转音频** 面板：选一个视频或音频文件，
点「转换为 WAV」，音轨会被抽出写成 WAV，落到 [输出目录](导出与输出目录)。

**不依赖 ffmpeg**，用的是程序内置浏览器引擎自带的解复用与解码能力。

## 怎么用

1. 点「选择文件」，挑一个 MP4 / MOV / M4A 等；
2. 面板立刻显示预估：

   ```text
   某视频.mp4 · 1:03:41 · 源文件 355.2 MB
   → 预计输出 1.02 GB（24-bit），转换需要约 1.71 GB 内存
   ```

3. 选输出位深（16 / 24-bit）；
4. 点「转换为 WAV」，进度条会显示解码与编码两个阶段；
5. 完成后状态栏给出文件名、时长、声道、采样率、位深与体积。

## 支持与不支持

| 支持 | 说明 |
|---|---|
| MP4 / M4V / MOV | H.264 + AAC 等常见组合 |
| WebM | VP8/VP9 + Opus/Vorbis |
| M4A / AAC / MP3 / FLAC / WAV / OGG | 纯音频文件同样可以走这里 |

| 不支持 | 原因 |
|---|---|
| MKV | 浏览器引擎不支持该封装 |
| H.265 / AC3 / DTS 等 | 内置解码器不含这些编码 |
| DRM 保护内容 | 无法解密 |

遇到不支持的文件会给出明确报错，不会生成半成品。

## 为什么这么快（而不是实时）

常见做法是把视频当音频播放一遍再录下来，那就是 1 倍速——1 小时的视频要等 1 小时。
这里直接把整个音轨解码成 PCM 再编码 WAV，所以是**秒级**：

```text
实测：355 MB、63.7 分钟的 H.264 + AAC MP4
→ 1024 MB 的 24-bit WAV，用时 14.5 秒（解码约 7 秒 + 编码约 6 秒）
实测：26 秒的小文件，用时 0.5 秒
```

代价是解码后的 PCM 要一次性驻留内存，所以有下列限制。

## 时限与内存

转换前会做三项检查：

| 检查 | 阈值 | 超出时 |
|---|---|---|
| 时长 | 6 小时 | 直接拒绝 |
| 输出 WAV 大小 | 3.8 GB | 拒绝（WAV 的 RIFF 长度字段上限约 4 GB） |
| 预计内存 | 当前可用内存 × 85% | 提示"请先关闭一些程序再重试" |

内存估算公式：

```text
预计内存 = 时长 × 48000 × 2 声道 × 4 字节 + 源文件大小
```

举例：1 小时的文件约需 1.7 GB。16 GB 内存的机器可以直接转 1～2 小时的视频。

> 位深只影响输出文件大小，**不影响内存占用**——解码缓冲永远是 float32 PCM，
> 所以内存不够时换 16-bit 没有帮助。

## 实用建议

- 转换过程中**不要关窗口**，但可以切到别的程序（界面不会假死，编码分块让出主线程）；
- 只要音轨的话，直接用原 FLAC / WAV 比转 MP4 更好——MP4 里的音轨是有损压缩的；
- 转出来的 WAV 可以直接「导入本地文件」进入 3D 渲染流程。
