# 参数模板（TXT 导入 / 导出）

「空间参数」面板底部有 **参数模板（TXT）**：导入一个 TXT 就立即套用，
导出则把当前参数写成同格式的 TXT。适合做预设、分享参数、批量复现听感。

## 格式

导出的文件本身就是可用模板，可直接手改：

```text
# asmr3d空间渲染器 · 空间参数模板 v1
# 每行一个参数，用 = 或 : 分隔；# // ; 开头的行是注释
# 数值可带单位，例如 0.4 m、80%、-12.5°

模板名称 = Food - Eating a fruit
方位角 = 30.0
仰角 = 12.0
距离 = 1.53
输出音量 = 66
渲染方式 = parametric
# 渲染方式可选：binaural / hrtf / parametric / bypass（当前 参数化 HRTF）
```

## 解析规则

按均衡器 EQ 文件的习惯设计，容忍各种手写习惯：

| 规则 | 行为 |
|---|---|
| 分隔符 | `=`、`:`、`：` 都行 |
| 注释与空行 | `#`、`//`、`;` 开头的行整行忽略 |
| 键名 | 中英文均可（见下表），**不区分大小写、忽略空格** |
| 数值 | 自动剥离单位：`0.4 m`、`80%`、`-12.5°` 都能识别 |
| 越界值 | 自动限幅，并在状态栏说明（不报错） |
| 认不出的行 | 跳过，并提示"忽略 N 行"，不会整体失败 |

### 支持的键名

| 参数 | 可用写法 |
|---|---|
| 方位角 | `方位角`、`方位`、`水平角`、`azimuth`、`azimuthdeg` |
| 仰角 | `仰角`、`高度角`、`elevation`、`elevationdeg` |
| 距离 | `距离`、`distance`、`distancem` |
| 输出音量 | `输出音量`、`音量`、`volume`、`gain` |
| 渲染方式 | `渲染方式`、`模式`、`mode`、`rendermode` |
| 模板名称 | `模板名称`、`name`（仅备注，不参与计算） |

### 渲染方式的可选写法

| 值 | 也可写成 |
|---|---|
| `binaural` | `双耳兼容`、`双耳`、`compatibility` |
| `hrtf` | `浏览器HRTF`、`browserHRTF` |
| `parametric` | `参数化HRTF`、`参数HRTF` |
| `bypass` | `直通`、`跳过` |

### 越界处理

| 参数 | 允许范围 |
|---|---|
| 方位角 | −90 ～ +90 |
| 仰角 | −30 ～ +30 |
| 距离 | 0.2 ～ 10 m |
| 输出音量 | 0 ～ 100 |

超出范围会被**限幅**而不是报错——这样你可以拿一份模板当基线，只改其中一两行
微调，其余照旧。限幅发生时状态栏会写出来，例如：

```text
已套用 方位角 45.0° · 仰角 30.0° · 距离 2.50 m · 音量 65% ·
渲染方式 浏览器 HRTF（仰角已限幅到 30.0°）· 忽略 1 行无法识别的内容
```

## 导入后会发生什么

滑块位置、右上角读数、声像位置、渲染链全部**立即更新**，不需要按播放。
如果当时正在播放，听感会实时跟着变。

## 存到哪里

导出的 TXT 落在与音频成品相同的 [输出目录](导出与输出目录) 里，文件名形如：

```text
Food - Eating a fruit_空间参数_2026-10-04T09-35-20.txt
```

## 小技巧

- 把常用听感存成几个模板（近耳、远场、偏左/偏右），切换对比很直观；
- 想只改距离，就复制一份模板把 `距离 = ` 那行改掉，其余不动；
- 模板里可以塞任意多注释行，方便写备注。
