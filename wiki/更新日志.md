# 更新日志

## v0.2 公测版

发布日期：2026-10-04 · 发布页：[v0.2-beta](https://github.com/tokc2327-code/ASMR3D/releases/tag/v0.2-beta)

### 新增

- **直播截获**：按应用进程回环实时取流，只抓所选应用；支持任意直播平台
- **同步录制**：截获期间边渲染边分段写盘，结束（或静音超时）后校验并合并为
  整段 WAV，附带 SHA-256
- **视频转音频**：本地抽取音轨转 WAV，不依赖 ffmpeg，63 分钟视频约 15 秒完成
- **空间参数模板**：TXT 格式导入 / 导出，导入即套用
- **统一输出文件夹**：所有成品写入 EXE 同级的 `输出` 目录
- **内置素材库扩充**：30 条 CC0 素材，分五类（双耳参考 / 近场 ASMR /
  环境距离 / 测试信号 / 单声道控制）

### 变更

- Windows 便携版**内置精简版 PowerShell 7.6.6**，直播截获开箱可用，无需另装
- **移除系统输出回环采集**——它会把 asmr3d 自身的输出一起抓回去，形成自激回路
  （多层回声、严重时啸叫）
- 界面改为粉色主题 + 插画背景，面板改为毛玻璃半透明
- 界面布局调整：直播截获移到右栏，已实现方法移到底部整行
- 「停止」不再清空播放位置
- 播放进度条支持实时拖动跳转

### 修复

- 播放进度条只能点击、无法拖动
- 保存位置选到盘符根目录（如 `D:\`）时报 `EPERM mkdir`
- 中文进程名在捕获列表里显示为乱码
- 截获列表里出现 asmr3d 自身（会造成自反馈）
- 选择文件后「转换为 WAV」按钮仍处于禁用状态

### 已知限制

- 直播截获仅 Windows，且仅支持按应用捕获
- 视频转换不支持 MKV 及 H.265 / AC3 等内置解码器覆盖不到的编码
- 长音频转换与导出的解码缓冲常驻内存，有前置提示
- Android APK 暂停维护，移动端请使用 PWA

## v0.1 测试版

发布日期：2026-10-04 · 发布页：[v0.1-test](https://github.com/tokc2327-code/ASMR3D/releases/tag/v0.1-test)

首个公开版本。

### 功能

- 四种渲染方式：双耳兼容（推荐）、浏览器 HRTF、参数化 HRTF、Bypass
- 空间参数：方位角 −90°～+90°、仰角 −30°～+30°、距离 0.2～10 m、输出音量
- 距离联动：反比衰减、空气吸收、近场低频、距离混响
- 完整文件离线导出与 5～120 秒实时片段导出，16/24-bit WAV
- 4 条内置 CC0 示例素材
- 网页版、Windows 便携版、Android APK

### 说明

- 该版本起，界面已明确区分"对象级 HRTF"与"双耳兼容整体调节"两种性质
  不同的处理，不声称能从普通双耳录音中恢复独立声源
