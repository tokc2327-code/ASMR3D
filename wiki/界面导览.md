# 界面导览

界面分四块：**左栏**音源与渲染控制、**中间**播放与空间参数工作区、
**右栏**直播截获、**底部**已实现方法。

## 左栏：声音对象与渲染设置

### 声音对象

| 控件 | 说明 |
|---|---|
| 软件内置素材库 | 内置 30 条 CC0 素材，按用途分五类 |
| 导入本地文件 | 选本机的音频或视频文件 |
| 播放 / 暂停 / 停止 | 停止**不会**清空播放位置，可原地继续 |
| 循环 | 播完自动从头再来 |

内置素材分五类：

```text
01 双耳参考      音乐盒、火车、人头录音、后院、淋浴扫动
02 近场 ASMR     耳语、指甲敲击、头发梳理、耳清洁、键盘……
03 环境距离      雨声、鸟叫、水龙头、旧剧场
04 测试信号      粉噪声、声学测量、脉冲响应
05 单声道控制    吃苹果、键盘、气泡、刷子（对象化测试用）
```

### 渲染方式

四个按钮随时切换，不中断播放。详见 [渲染方式与空间参数](渲染方式与空间参数)。

### 导出成品音频

两种导出范围：

| 范围 | 特点 |
|---|---|
| 完整文件（离线渲染） | 比实时快，整段一次渲染，不可取消 |
| 指定片段（实时捕获） | 5～120 秒，按播放速度捕获，可取消 |

位深可选 16-bit / 24-bit。详见 [导出与输出目录](导出与输出目录)。

### 对象元数据

只读信息：文件名、类别、声道、采样率、时长、许可。

## 中间：播放与遥测

### 音频播放进度

- 拖动进度条**实时**跳转（不是松手才跳）；
- 「后退 / 前进 10 秒」按钮；
- 播放中进度条跟随刷新。

### 空间参数与模板

四个滑块：方位角、仰角、距离、输出音量。右上角有「复位」回到默认值。
参数区同时服务于本地播放和直播截获；调参和导入模板会实时作用于两条输入链。
下方保留 [参数模板](参数模板) 的导入/导出。

### 空间参数读数

六个实时数值：

| 读数 | 含义 |
|---|---|
| 距离增益 | 按 1/r 反比算出的衰减 |
| 双耳声级差 (ILD) | 左右耳的响度差，正数表示偏左 |
| 双耳时差 (ITD) | 左右耳的到达时间差 |
| 空气吸收 | 当前高频低通截止频率 |
| 近场提升 | 1 m 内额外提升的低频量 |
| 基础输出延时 | AudioContext 报告的设备延时 |

下面的流程图 `Stereo L/R → Field pan → Elevation EQ → Distance → Limiter`
会随渲染方式变化，直观显示信号经过了哪些环节。

### 视频转音频

选文件 → 看预估（时长 / 预计输出大小 / 需要多少内存）→「转换为 WAV」。
详见 [视频转音频](视频转音频)。

## 右栏：直播截获

抓取正在播放的直播音频并实时做 3D 渲染，可选同步录制成品。
详见 [直播截获](直播截获)。

## 底部：已实现方法

把当前版本实现的处理逐条列出（12 项），每项对应上面某个控件背后的算法。
它同时充当"功能清单"，方便确认某个能力是否已经落地。

## 状态栏

- 左下：当前状态提示（"正在播放空间化对象"、"已停止播放，播放位置已保留"等）；
- 右下：`AudioContext` 状态、采样率、基础延时。
