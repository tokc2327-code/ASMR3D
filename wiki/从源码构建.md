# 从源码构建

面向想改代码或自己打包的人。只想用工具的话看 [安装与运行](安装与运行) 就够了。

## 环境要求

| 项目 | 版本 / 说明 |
|---|---|
| Node.js | 24.x（开发时使用 24.21.0） |
| npm | 11.x |
| Electron | 44.5.1（devDependency，首次打包需联网下载） |
| PowerShell 7 | 用于运行直播截获脚本与图标生成（Windows） |
| Android APK | 另需 JDK + Android SDK（当前暂停维护） |

## 目录结构

```text
renderer/   界面与全部音频算法（Web Audio）
desktop/    Electron 主进程、IPC、捕获与录制
tools/      构建脚本、测试脚本、原生捕获脚本
materials/  30 条 CC0 测试素材 + 来源清单
docs/       技术文档
wiki/       本 Wiki 的源文件
dist/       构建产物（已在 .gitignore 中）
```

## 开发运行

```powershell
npm install

# 网页版（含局域网手机访问）
node .\renderer\server.mjs

# 桌面开发模式（另开一个终端）
node_modules\electron\dist\electron.exe .\desktop\main.cjs
```

桌面开发模式下的输出目录是项目的 `dist\输出`。

## 打包

```powershell
npm run exe:release        # Windows 便携版（含图标合成、移动包、zip）
npm run build:mobile       # 网页版 / 手机 PWA 包
npm run apk:release        # Android APK（需 Android 工具链）
```

`exe:release` 会顺带把一份精简版 PowerShell 7 复制进 `resources\pwsh`，
让最终用户不需要另外安装。

## 自测脚本

```powershell
node tools\live_capture_smoketest.mjs --list    # 枚举音频会话
node tools\live_capture_smoketest.mjs msedge 10 # 命令行捕获 10 秒
node tools\recorder_selftest.mjs                # 分段录制/合并自检
node tools\inspect_wav.mjs <file.wav>           # 检查任意 WAV 的格式与电平
node tools\cdp_live_test.mjs 10                 # 驱动运行中的应用做端到端验证
node tools\app_screenshot.mjs shot.png 1600 1000  # 截图（--full 截整页）
pwsh -File tools\make_icons.ps1 -Source <图>     # 重新生成全套图标
```

调试直播截获时可以设 `ASMR3D_CAPTURE_LOG=<路径>`，主进程会把实际启动的命令行
写进日志（用来确认用的是包内还是系统的 PowerShell）。

## 发布新版本

发布顺序与准入条件以[根目录 AGENTS.md 的发布流程](https://github.com/tokc2327-code/ASMR3D/blob/main/AGENTS.md#发布流程后续版本统一执行)为准；操作示例见仓库 `docs/GITHUB_上传指南.md`。历史交接材料中的直接上传步骤不作为当前发版入口。

先在开发分支运行版本号更新（将示例版本替换为本次新版本），并随源码、文档一起提交 PR：

```powershell
node tools\bump_version.mjs 0.3.2 公测版 v0.3.2-beta --dry-run
node tools\bump_version.mjs 0.3.2 公测版 v0.3.2-beta
```

显式传入完整发布标签（如 `v0.3.2-beta`），并与新版本号一起替换；脚本默认标签只包含 major.minor，不适用于补丁版本发布。

`bump_version.mjs` 会同步修改界面、产物名、发布标签及文档中的版本字符串；这些改动必须在合并前完成审查。

PR 完成审查、验证并经授权合并后，从干净的主分支提交构建和验收产物，再发布：

```powershell
node tools\build_exe.mjs
node tools\build_github_package.mjs
# 确认最终产物验收通过，脚本版本与发布标签正确，再执行上传
$env:ASMR3D_SKIP_SOURCE_UPLOAD = "1"
node tools\github_upload.mjs
```

## 贡献

欢迎提 Issue 与 PR。提交前请确认：

1. `node --check` 能过（改过 JS 的话）；
2. 相关自测脚本通过；
3. 打包后能启动、能播放、能导出。
